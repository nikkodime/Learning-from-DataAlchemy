# Content calendar

Operationalizes the cadence from `00-strategy.md` §7: two new scripts a week, sourced from `02-content-bank.md`, each one adapted across every platform per `templates/platform-adaptation-cheatsheet.md` before moving to the next.

## Monthly block (copy this)

```
## [Month Year]

| Week | Script (from 02-content-bank.md) | Pillar | Status | Shot date | Platforms live |
|------|-----------------------------------|--------|--------|-----------|----------------|
| W1   | [pillar A or B item]              |        | [ ]    |           |                |
| W1   | [rotating C-F item]               |        | [ ]    |           |                |
| W2   | [pillar A or B item]              |        | [ ]    |           |                |
| W2   | [rotating C-F item]               |        | [ ]    |           |                |
| W3   | ...                                |        | [ ]    |           |                |
| W4   | ...                                |        | [ ]    |           |                |
```

Status values: `[ ]` queued, `[w]` written (spoken script + all platform copy done), `[f]` filmed, `[x]` published everywhere.

## Rotation rule

Slot 1 each week always comes from Pillar A (Hiring & Talent Decisions) or Pillar B (Leadership & Culture) — these have the deepest existing bank and are the account's proven core. Slot 2 rotates through C, D, E, F in order, so every pillar gets covered roughly once a month rather than the account drifting into only one theme.

## Rule for keeping this current

At the end of each month: mark everything shot in `02-content-bank.md`, then pull the next 8 items (2 per week) into next month's block, following the rotation rule above. Keep no more than one month queued at a time — see `00-strategy.md` §9 on why this system stays alive by staying short-horizon.
