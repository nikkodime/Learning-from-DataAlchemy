# HireHax content system

A complete, repeatable content creation system for HireHax (boutique executive search & leadership advisory for life sciences), built from the firm's existing brand assets: `HireHax_Deck.pdf`, `hirehax-brand-book.html`, and `Retained Search Engagement Letter & SOW (template).md`. No content had been published before this system was built; this closes the gap between an already-strong brand and an empty feed.

## Read in this order

1. **`00-strategy.md`** — positioning, ICP, the five content pillars, channels, cadence, and how success is measured.
2. **`01-voice-and-style.md`** — the verbatim voice rules from the brand book, plus a before/after example and a pre-publish checklist. This is the file to reread most often.
3. **`02-content-calendar.md`** — the monthly planning shape, filled in one month at a time.
4. **`templates/`** — one template per format, each with the structure explained and a fully worked, ready-to-adapt example:
   - `signal-post.md` — weekly market-intelligence post.
   - `thought-leadership-post.md` — the Search / Org Design / Future-Ready pillars.
   - `principle-post.md` — founder POV, built from the deck's four operating principles.
   - `case-study.md` — anonymized "Selected Work," reusing the deck's own proven format.
   - `newsletter-monthly.md` — the monthly digest + featured piece.
5. **`04-example-drafts.md`** — one full first week of ready-to-review posts, showing the system running end to end.
6. **`05-production-workflow.md`** — the actual weekly pipeline (source → draft → voice QA → publish → repurpose), including a ready-to-use AI-drafting prompt that encodes the voice rules.

## What this is not

This system does not invent new positioning. HireHax's positioning, thesis, and voice were already finished and approved in the brand book and deck; this system's only job is to turn that into a sustainable publishing cadence. If the positioning itself needs to change, that's a brand decision to make first, separately from this content system.

## Known gap, called out honestly

The "HireHax Radar" (an automated market-intelligence engine) is referenced in the brand book's messaging but doesn't exist yet as a built tool. This system's Signal pillar runs on manual sourcing until it does. Don't publish copy that implies a live tracking engine exists.

## The adjacent venture

A second, distinct initiative (an AI-readiness assessment product, internally floated as "Health Advisory Hub") is in progress alongside HireHax, sharing the same Google Workspace. It has a different audience and funnel and is deliberately kept out of this system, per `00-strategy.md` §7, so the two brands don't dilute each other in one feed. When that venture's name and positioning are finalized, this system can be used as a template to build its own.
