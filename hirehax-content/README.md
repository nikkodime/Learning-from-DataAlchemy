# HireHax content system

A complete, repeatable content creation system for HireHax's social/video content — Nikko Dimitrov's personal-brand thought-leadership channel on leadership, hiring, and organisational scale for CEOs, boards, and senior operators in life sciences and technology.

## Provenance (read this first)

The real source of truth is `source/HireHax_Social_Content_Claude_Knowledge_Base.md` — an export consolidating HireHax social content developed across prior working sessions: 22 finished or recovered scripts, a topic bank, a proven video formula, and explicit voice rules. Everything else in this folder organizes and operationalizes that material; it doesn't replace it. An earlier draft of this system was built from HireHax's institutional executive-search collateral (deck, brand book) before this knowledge base was available, and inferred a more formal "boardroom" voice that turned out to be for a different purpose (client proposals, not content) — see `00-strategy.md` §1 and §4 for how that's resolved.

## Read in this order

1. **`00-strategy.md`** — positioning, audience, the two voice registers and where each applies, six content pillars, platform strategy, and the cadence this system adds on top of the existing material.
2. **`01-voice-and-style.md`** — the real, established voice rules verbatim from the knowledge base, the proven five-beat video formula, and a pre-publish checklist.
3. **`02-content-bank.md`** — the single most important operational addition: every one of the 22 developed scripts plus every topic-bank idea, tracked as `DEVELOPED` / `AVAILABLE` / `SHOT` by pillar, so content never accidentally repeats a topic.
4. **`03-content-calendar.md`** — the cadence (two scripts a week) and pillar-rotation rule, filled in one month at a time.
5. **`templates/`**
   - `video-script-master.md` — the master format every script gets drafted in (the knowledge base's own "Default output template," annotated).
   - `platform-adaptation-cheatsheet.md` — how one spoken script becomes LinkedIn, IG/TikTok, YouTube Shorts, Facebook, and Threads/X versions without just copy-pasting.
6. **`04-example-drafts.md`** — two brand-new, complete scripts (not already in the knowledge base), drafted end to end through this system, proving it works.
7. **`05-production-workflow.md`** — the full repeatable pipeline (select → script → voice QA → film → adapt → publish → track), including an AI-assisted drafting prompt that encodes the real voice rules, and filming/B-roll notes from the knowledge base.

## What this system adds versus what already existed

The knowledge base already had strong voice, format, and 22 scripts. What it didn't have: a tracker distinguishing published material from still-available ideas, a stated publishing cadence, and a documented path from "topic bank entry" to "shot, cross-platform, published piece." Those three things are what `02-content-bank.md`, `03-content-calendar.md` §7 of the strategy doc, and `05-production-workflow.md` add.

## What this is not

Not the search firm's formal client-facing register (proposals, SOW, engagement letters) — that's a separate, already-established "boardroom" voice living in HireHax's institutional brand book, out of scope here. Not a rewrite of the existing 22 scripts — they're preserved as-is in `source/` and indexed, not altered.
