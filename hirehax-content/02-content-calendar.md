# Content calendar

Operationalizes the cadence from `00-strategy.md` §6. Copy the month block below and fill it in at the start of each month rather than planning further ahead than that. This is intentionally low-ceremony: a spreadsheet or Notion board works too, this file just defines the shape.

## Monthly block (copy this)

```
## [Month Year]

Newsletter theme: [one line — usually the month's strongest Signal item or expanded piece]
Newsletter publish date: [first week of month, pick a fixed weekday]

| Date | Pillar | Format | Status | Notes |
|------|--------|--------|--------|-------|
| Mon  | Signal | Short  | [ ]    |       |
| Wed  | Search as Architecture / Org & Leadership Design (alternate) | Medium | [ ] | |
| Fri  | Future-Ready / Operating Principles (alternate) | Medium | [ ] | |
| Mon  | Signal | Short  | [ ]    |       |
| Wed  | Search as Architecture / Org & Leadership Design (alternate) | Medium | [ ] | |
| Fri  | Selected Work (once/month) or Future-Ready / Operating Principles | Medium | [ ] | |
| ...  | | | | (continue for remaining weeks) |
```

Status values: `[ ]` not started, `[d]` drafted, `[r]` reviewed against voice checklist, `[x]` published.

## Rule for keeping this current

At the end of each month, spend the same 20 minutes as the strategy review in `00-strategy.md` §8 filling in next month's block. Don't let the calendar get more than one month ahead. A content system that plans a quarter out gets abandoned the first time reality diverges from the plan; a one-month system stays alive.
