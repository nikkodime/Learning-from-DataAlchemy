# Master template: video script + platform adaptation

This is the knowledge base's own "Default output template" (Section 6), annotated. It's the single format every new piece of content should be drafted in. Everything else (LinkedIn text, IG/TikTok captions, Shorts metadata, Threads/X) is adapted *from* the spoken script, never written independently — see `platform-adaptation-cheatsheet.md`.

## Before drafting

1. Pick the next item from `02-content-bank.md` (per the rotation in `03-content-calendar.md`), or a deliberate sequel to a `DEVELOPED` item.
2. Identify the target decision-maker (which primary-audience segment from `00-strategy.md` §3) and the uncomfortable truth this piece names.
3. Confirm no accidental overlap with an existing `DEVELOPED` script — if there's overlap, it must be a conscious sequel or new angle, not a repeat.

## The template

```markdown
## Title

Audience:
Pillar:
Central truth:

### Hook options
1.
2.
3.

### Final spoken script

### LinkedIn caption

### Instagram / TikTok caption

### YouTube Shorts title + description

### Threads / X version

### Pinned comment

### 5-6 B-roll cues
```

## Field-by-field guidance

- **Audience**: name the specific primary-audience segment (CEO/founder, board/chair, CHRO, investor) this piece is aimed at, not just "leaders."
- **Pillar**: one of A-F from `00-strategy.md` §5.
- **Central truth**: one sentence, the uncomfortable thing this piece says. Write this before the script, not after — if you can't state it in one sentence, the script isn't focused enough yet.
- **Hook options**: write three, pick the sharpest. Each must pass the "works with zero context in three seconds" test from `01-voice-and-style.md`.
- **Final spoken script**: follow the five-beat structure exactly (hook → call-out → truth/reframe → educational shift → punchline). 45-90 seconds spoken, which is roughly 100-220 words depending on pacing.
- **LinkedIn caption**: the full strategic version, can extend beyond the spoken script with one extra layer of executive framing. This is the deepest-context platform.
- **Instagram / TikTok caption**: tight emotional hook, clean short paragraphs, punchline, restrained hashtags (2-4 max, no hashtag spam).
- **YouTube Shorts title + description**: title must be searchable (what would the target audience type into search), description concise.
- **Threads / X version**: compress to the single central contrast or truth — one or two lines, not a re-post of the LinkedIn caption.
- **Pinned comment**: optional but recommended for higher-stakes pieces — a sharpened one-line summary or an open question that invites the primary audience specifically to respond.
- **B-roll cues**: exactly 5-6, per the proven formula. Use the bank in `05-production-workflow.md` §Production notes; premium/real corporate imagery, never generic HR stock footage.
